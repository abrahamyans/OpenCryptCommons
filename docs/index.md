# OpenCryptCommons Documentation

OpenCryptCommons is an open-source toolkit under development for selective disclosure, threshold trust, and crypto-agile post-quantum migration.

## Documentation map

- `architecture.md` — component boundaries and design rules;
- `roadmap.md` — planned development phases;
- `mvp-scope.md` — exact boundaries of the first working release;
- `threat-model.md` — initial assets, attackers, risks, and non-goals;
- `standards.md` — standards and implementation policy;
- `implementation-plan.md` — practical engineering sequence.

## Current status

The repository contains a Phase 1 Rust foundation. Cryptographic backends are intentionally not implemented until the project records its standards choices and review requirements.
